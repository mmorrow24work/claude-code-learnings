# Claude Code Learnings

Personal notes and discoveries from learning [Claude Code](https://claude.ai/code) — Anthropic's official CLI for Claude.

## Structure

| Folder | Contents |
|--------|----------|
| `cli/` | Commands, flags, and slash commands |
| `hooks/` | Automation with hooks |
| `mcp/` | MCP servers and integrations |
| `agents/` | Subagents, parallel tasks, agent types |
| `memory/` | The persistent memory system |
| `settings/` | Configuration, permissions, env vars |
| `tips/` | Miscellaneous tips and tricks |
| `til/` | Today I Learned — short dated entries |
